### Load, failure order and deployment

Uvicorn and Streamlit both started on loopback and their health endpoints returned 200. The application was exercised through TestClient and AppTest. On this 16-logical-CPU Windows workstation with SQLite 3.49.1, the 110,955-byte risk model's first status lookup took about 2 seconds including first-use imports. The larger lists used replicated synthetic fixtures with distinct IDs. These timings exclude remote network and browser rendering. The whole-order list has already lost interactive response time by 1,000 active rows. It reopens and parses state for each row in addition to running one-row inference. Pagination, a shared state snapshot and batched prediction should precede tuning the model loader. ## 3. Re-derived metrics and claims — 8/10

Committed synthetic results reproduce across the baseline, response scenarios, capacity comparisons and ceiling. The data do not validate policy economics or language accuracy in the field.

### Pre-reply flagging

FPR is `FP / 583`, FNR is `FN / 601`, and the base loss is `450 × FP + 650 × FN`. At the frozen 0.50 threshold, the model's raw synthetic ROC AUC was 0.7353 and Brier score was 0.2068, versus 0.2499 for a constant training-prevalence prediction. These describe the generator and this split. They give no calibrated merchant probability. ### Generator ceiling

Reconstructed the generator's seeded draws and 51% calibration. The offset was approximately 1.487396, and the reproduced Bernoulli draws matched all 6,000 committed labels. Independently integrated the private noise with 64-point Gauss–Hermite, compared with 24 points in the project, and summed probability mass within each fixed budget. On validation, served / guarded oracle / unrestricted oracle expected recall were **41.06% / 41.58% / 43.12%** with 353 flags. On test the same values were **40.57% / 41.06% / 42.40%** with 341 flags. Ordinary orders supplied 352 of 356 observed misses (98.88%), leaving four in the latent cluster. The top 204 out of 1,024 ordinary test rows captured **28.75%** of their expected failure mass, versus **19.92%** for uniform random screening. Ordinary conditional variance share was 88.78%. That share describes binary-outcome variance under this generator. It does not imply 88.78% of real failures are intrinsically unpredictable. Better data, outreach and a different operating target fall outside this fixed-capacity bound.
